git config: para poder obtener informacion o actualizar informacion de configuracion en git, por ejemplo nombre y correo 
			--global aplica para todos los repositorios del usuario especifico.
			--system aplica para todos los repositorios de todos los usuarios.
			--local o sin flag es para el repositorio actual.
